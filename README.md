# Análisis de Consumo de Combustible con Power BI

## Descripción del Proyecto

Este proyecto presenta un análisis de consumo de combustible y variación de precios de gasolina utilizando registros personales de carga de combustible vehicular.

El análisis fue desarrollado en Power BI con el objetivo de identificar patrones de consumo, tendencias en el precio de la gasolina, rendimiento del vehículo y gastos acumulados a lo largo del tiempo.

---

## Objetivos

- Analizar el comportamiento del consumo de combustible
- Identificar incrementos en el precio de la gasolina
- Medir el rendimiento del vehículo
- Evaluar gastos anuales de combustible
- Desarrollar visualizaciones interactivas para análisis de datos

---

## Herramientas Utilizadas

- Power BI
- Power Query
- DAX
- Python
- Google Colab

---

## Métricas Analizadas

- Gasto total en combustible
- Rendimiento promedio del vehículo
- Tendencia del precio de gasolina
- Consumo anual
- Variación de costos por periodo

## Hallazgos Principales

- El precio de la gasolina muestra una tendencia creciente durante los años analizados
- El gasto anual en combustible incrementa progresivamente con el tiempo
- El rendimiento del vehículo presenta variaciones asociadas a condiciones de manejo y precios de combustible
- Los registros históricos permiten identificar patrones útiles para control de gastos personales

## Modelo de Machine Learning

Como parte complementaria del análisis, se desarrolló un modelo de Machine Learning utilizando Python y Google Colab con el objetivo de explorar patrones de comportamiento y capacidades predictivas a partir de los registros históricos de consumo de combustible.

El modelo incluye procesos de:
- preparación y limpieza de datos
- análisis exploratorio
- entrenamiento de modelos
- evaluación de resultados
- visualización de métricas
